# 🏢 (주)수협개발 건설공사 만족도 조사 집계 웹 애플리케이션

종이(지류)로 수합된 설문지(PDF, JPG, PNG 파일)를 웹 브라우저에서 직접 보면서 신속하게 입력하고, 실시간 누적 집계 및 엑셀 호환 CSV 파일로 내려받을 수 있는 비개발자 맞춤형 Streamlit 애플리케이션입니다.

---

## 🌟 주요 기능

1. **지류 설문지 보며 바로 입력 (듀얼 뷰)**
   - 스캔본 이미지(PNG, JPG, JPEG) 및 PDF 문서를 바로 업로드하여 화면에서 보면서 입력할 수 있습니다.
   - 다중 페이지 PDF의 경우 페이지 선택 기능 지원.
2. **평가 점수 자동 집계**
   - 7개 세부 문항(1~5점)을 선택하고 저장 버튼을 누르면 **총점(합계)** 및 **평균(소수점 첫째 자리)**이 자동 계산됩니다.
3. **영구 누적 저장 및 엑셀 호환**
   - 입력된 모든 설문은 같은 폴더 내 `survey_data.csv`에 계속 누적 저장됩니다.
   - 한글 깨짐이 없는 **UTF-8-SIG** 포맷으로 저장되어 Microsoft Excel에서 더블 클릭만으로 바로 열립니다.
4. **실시간 대시보드 및 통계 시각화**
   - 실시간 KPI 요약 카드 (총 설문 수, 전체 평균 만족도, 최고 점수 등)
   - 세부 문항별 평균 점수 막대 그래프 차트
   - 검색 필터(발주사, 공사명, 담당자 이름) 기능이 포함된 실시간 데이터 테이블
   - **개별 행(설문) 삭제 기능**: 표에서 잘못 입력된 줄을 클릭하거나 드롭다운에서 선택하여 즉시 삭제(삭제 시 파일 자동 저장 및 실시간 새로고침)
   - 원클릭 엑셀용 CSV 다운로드 버튼

---

## 🚀 가장 쉬운 실행 방법 (원클릭 실행)

1. 폴더 안에 있는 **`run.bat`** 파일을 마우스로 **더블 클릭**합니다.
2. 검은색 창이 뜨면서 필요한 라이브러리를 자동으로 확인/설치한 후, 웹 브라우저(Chrome, Edge 등)에 집계 시스템 화면이 자동으로 열립니다.
3. 프로그램을 종료하려면 검은색 명령 프롬프트 창을 닫으시면 됩니다.

---

## 🛠️ 직접 명령어로 실행하는 방법 (선택 사항)

명령 프롬프트(CMD) 또는 PowerShell에서 아래 명령어를 순서대로 입력하여 실행할 수도 있습니다.

```bash
# 1. 패키지 설치
pip install -r requirements.txt

# 2. 웹 애플리케이션 실행
streamlit run app.py
```

## 📊 입력 및 저장 항목 안내

| 분류 | 항목명 | 설명 |
| :--- | :--- | :--- |
| **기본 정보** | 등록일시 | 저장 시 현재 날짜 및 시간이 자동 기록됩니다. |
| | 발주사 | 설문 대상 발주사 (필수) |
| | 공사명 | 공사명 / 프로젝트명 (필수) |
| | 계약기간 | 공사 기간 (예: 2026.01.01 ~ 2026.06.30) |
| | 담당자소속 | 작성자/담당자 부서 (예: 시설관리팀) |
| | 담당자이름 | 담당자 성함/직급 |
| **만족도 평가**<br>(각 1~5점) | 소통_설명및협의 | 공사 내용 설명 및 업무 협의 원활성 |
| | 소통_공사기간준수 | 공정 및 납기 일정 준수 여부 |
| | 품질_계약내용실행 | 설계 및 계약 사양 충실 이행 |
| | 품질_설계개선 | 현장 여건 반영 및 설계 개선 제안 |
| | 안전_안전사고예방 | 현장 안전 수칙 및 재해 예방 조치 |
| | 기타_민원관리 | 소음/분진/민원 처리 적극성 |
| | 종합_전반적만족도 | 공사 전반에 대한 종합 만족도 |
| **자동 연산** | 합계 | 7개 항목 점수 단순 합산 (최대 35점) |
| | 평균 | 7개 항목 점수의 평균 (소수점 1자리 반올림, 최대 5.0점) |

## 📁 파일 구성 안내

- **`app.py`**: 웹 애플리케이션의 핵심 소스 코드
- **`run.bat`**: 비개발자용 원클릭 실행 파일
- **`requirements.txt`**: 필요한 파이썬 라이브러리 목록
- **`survey_data.csv`**: 설문 결과가 자동으로 누적 저장되는 엑셀 호환 데이터 파일 (설문 등록 시 자동 생성)
- **`README.md`**: 본 설명서
